Development Tools & Frameworks

Frontend quality, React patterns, research, and workflow references

impeccable — Design System Enforcement

21 skills with 20 steering commands. The key insight: AI-generated frontends tend toward generic patterns (overused fonts, gray-on-colored, nested cards). Impeccable explicitly combats this with anti-patterns and design vocabulary.

Must-use commands: /audit (before shipping any UI), /polish (final pass), /distill (simplify complex views), /typeset (typography), /overdrive (when you want maximum visual impact).

Recommendation: Always active for frontend projects. Pair with no-use-effect for React work.

no-use-effect — React Quality Gate

5 strict rules: derive state via useMemo, use data-fetching libraries (React Query/SWR), prefer event handlers, use useMountEffect, key-based resets. Based on React's official "You Might Not Need an Effect" guidance.

Recommendation: Always active. Zero context cost, maximum code quality impact.

Aggregates across Reddit, X, YouTube, TikTok, HN, Polymarket, Bluesky, Instagram, Truth Social. Requires SCRAPECREATORS_API_KEY.

Key insight: Sub-agents load only their description into the main context (saving tokens). The full system prompt loads only when Claude delegates to them.

Multi-instance coordination for tasks requiring parallel work with inter-agent communication

Experimental Feature: Agent teams require CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 in settings.json (already configured by the installer). Requires Claude Code v2.1.32+.

When to Use Agent Teams vs Sub-Agents

DimensionSub-Agents (Layer 12)Agent Teams (Layer 13)
ContextOwn window, results return to callerOwn window, fully independent
CommunicationReport back to main agent onlyTeammates message each other directly
CoordinationMain agent manages all workShared task list, self-coordination
Token costLower (results summarized)Higher (each is separate instance)
Best forFocused tasks where only result mattersComplex work requiring discussion

Delavalom Agent Team Patterns

Parallel Code Review
3 teammates review the same PR from security, performance, and test coverage perspectives simultaneously. Lead synthesizes findings.
Competing Hypothesis Debug
5 teammates investigate different root causes in parallel, actively debating each other's theories. Surviving theory is the actual cause.
Cross-Layer Feature Build
Frontend (TypeScript), backend (Go/Python), and test teammates each own their domain. Shared task list coordinates interfaces.
Research Sprint
Teammates research different market segments, competitors, or technology options simultaneously. Lead produces unified brief.
